# Da zero a professionista con Claude

Percorso pratico per imparare a usare Claude (chat, progetti, Claude Code, agenti,
skill, automazioni) partendo da zero, con esempi legati al lavoro da sistemista /
help desk. Ogni lezione: max 1 ora, con un esercizio pratico.

## Modulo 1 — Fondamenta
1. Come "parlare" con Claude: prompting efficace
2. Chat vs Progetti vs Claude Code: quale strumento per quale compito
3. Istruzioni personalizzate e memoria (preferenze, contesto persistente)

## Modulo 2 — Claude Code per il sistemista
4. Claude Code: cos'è, come funziona, primi comandi
5. Esplorare un progetto/repository con Claude
6. Automatizzare script (PowerShell/Bash) con Claude
7. Git assistito: commit, branch, pull request

## Modulo 3 — Agenti e Skill
8. Sub-agenti: cosa sono e quando usarli
9. Creare la tua prima Skill personalizzata
10. MCP (Model Context Protocol): collegare Claude a strumenti esterni
11. Automazioni e Routine: far scattare azioni da solo

## Modulo 4 — Applicazioni pratiche da sistemista
12. Troubleshooting di rete assistito
13. Documentazione automatica (da log/ticket a report leggibili)
14. Un "assistente help desk" fatto con Skill + automazioni
15. Capstone: progetto finale e checklist di sicurezza/best practice
